# Revised UI Design Atlas: 20-concept implementation audit (R8)

Date: 2026-10-14
Scope: Independent, read-only comparison of the revised 20-concept atlas with the merged R7 implementation. This audit owns no product changes; root owns implementation and validation.

## Evidence and interpretation

Read the revised reference extraction and diff at `.worknotes/browser-evidence/design-concepts-atlas-revision-r8.txt` and `.worknotes/browser-evidence/design-concepts-atlas-revision-r8.diff`, the revised atlas HTML/PDF and PDF text extraction, and R7 handoff `.worknotes/design-concepts-overhaul-r7-2026-10-14.md`. Compared those directions with `packages/ui/src/components/foundation/design-modes.ts`, `packages/ui/src/design-modes.css`, `apps/docs/src/styles.css`, `apps/docs/src/components/design-mode-preview.tsx`, and `apps/docs/src/analytics-workspace.tsx`.

The revised atlas explicitly separates **visual styles** (most cases), **Material / Fluent design systems**, **Bento Grid layout**, **Dark UI theme**, and **Terminal / Spatial interface approaches**. A web implementation can express those visual and interaction principles; it should not imply native WinUI/AcrylicBrush, AR/VR spatial anchors, gaze/hand input, or a new TUI framework. Bento and Spatial are correctly represented as `recipe` values that alter the common analytics composition, while design modes remain the existing 21 IDs. R7 records preserved Basic/PRISM, picker/state/URL/portal/iframe contracts; this audit recommends keeping them intact.

Status in the matrix means fulfillment of the reference's distinguishing principle in current source, not certification against a platform's official system or visual browser sign-off. “Covered” means no concept-specific change is recommended from this static review. “Partial” identifies a concrete implementation gap or over-application worth addressing within the existing architecture.

## Highest-value scoped changes

1. Reduce Glass/Fluent material spread: ordinary table/body surfaces stay opaque; Acrylic-like blur is chiefly for flyouts/nav overlays. Keep Glass's colored backdrop and translucent showcase cards.
2. Give Clay its cushion relief on the primary action and one card while flattening routine navigation/data. Keep existing palette/radii so the material remains unmistakable.
3. Add small, actual behavior witnesses for Skeuomorphic value control, Terminal keyboard affordance, and Retro titlebar/window behavior. Strengthen Pixel with one scaled pixel asset and state-linked progress; keep readable body text.
4. Retain Neobrutalism's bold border/color/hard shadow identity and improve only the primary control's pressed response. Do not water the style down.
5. Keep Bento as layout and Spatial as a 2D spatial composition recipe; keep Dark UI classified as a theme and Material/Fluent named as system/material directions. Avoid promising native platform features or introducing a new framework.

No source changes, browser work, build/test, Git operation, or publication was performed for this delegated audit. This is static evidence review; final screenshots/interaction validation remain root's task. Existing Basic/PRISM and 21-mode/picker/state contracts are out of scope and must remain preserved.
