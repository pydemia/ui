# prism-management-tools 목표 수용 감사 (2026-10-14)

현재 `prism/frontend` `2eeb26ff10274745f9d86897c2f2828bff002b98`의 기준 편집·삭제·태그, 회사 과제, 포지션 확인 소스와 SCSS를 대조했다. 기준명 검사, 영향 포지션 확인 후 재매핑, 26px 상태 태그, 회사명/복사/340px 과제 영역, 체크 카드가 이 그룹의 목적이다. 산업·직무 블럭의 전체 생성/수정/삭제 절차는 완료 판정된 `prism-position-blocks`가 담당한다.

설치형 일반 기준 편집기는 `checkedName`을 현재 입력 이름과 비교해 이전 이름의 검사 결과로 저장하거나 설명을 생성하지 못하게 한다. 제출 이름을 trim한다. 재매핑은 `loadState`와 `loadedTargetId`가 현재 대상의 성공 조회를 가리킬 때만 확정할 수 있고 삭제·반영 중·삭제 대상 기준을 후보에서 제외한다. 조회 오류는 빈 영향 목록으로 취급하지 않고 재시도한다. 회사 과제는 원본의 회사명/복사/본문 구조를 적용했고 기본 Clipboard API와 host callback의 성공·실패를 표시한다.

대상 테스트 4개가 이름 변경 뒤 검사 무효화, 새 대상의 오래된 영향 조회 차단, 부적절한 대체 후보 제외, 복사 callback·기본 Clipboard API를 확인했다. 전체 PRISM 테스트 359개와 문서 예제 타입 검사 49개, 사이트 빌드가 통과했다. 로컬 브라우저는 기본 편집·재매핑, 오류/재시도, 긴 태그·긴 과제, 320px 폭을 확인했다.

새 외부 shadcn 소비자 `/tmp/prism-management-tools-local-sprmXh`에 로컬 레지스트리 종속 항목까지 설치했다. PRISM TSX 18개와 PRISM CSS·일반 토큰이 로컬 레지스트리와 바이트 단위로 일치했고 완전 예제 타입 검사, Vite 빌드, Pretendard와 라이선스 고지가 통과했다. 브라우저에서 검사→설명 생성→저장 의도, 재매핑 선택→확정 의도, 복사 완료를 확인했다. 처음에는 320px 대화상자의 520px 표가 잘려 마지막 열이 보이지 않았다. 그리드 항목 `min-width:0`을 적용해 문서 폭 320px, 대화상자 296px, 표 스크롤 영역 264px/내용 520px로 고쳤다. 좁은 화면에서도 마지막 열의 선택기를 열고 선택했다. 클립보드 내용의 브라우저 외부 readback은 빈 값을 돌려줘 실제 OS 클립보드 내용은 확인하지 못했지만 기본 Clipboard API 인수는 테스트로 확인했다.
