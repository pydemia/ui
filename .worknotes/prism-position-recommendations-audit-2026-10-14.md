# 추천 포지션 그룹 재감사 (2026-10-14)

대상은 58개 목표 중 `prism-position-recommendations` 한 그룹이다. 원본 `prism/frontend`의 `dev`·`origin/dev`는 `2eeb26ff10274745f9d86897c2f2828bff002b98`로 일치하고 작업 트리는 깨끗했다. 현재 인증된 배포 화면의 소스 SHA는 확인되지 않았다. 문서 대응표에는 추천 템플릿·카드의 SCSS, 더보기 버튼과 JSON 패널 사용처를 추가했다.

원본은 카드 1·2개의 가로/단일 배치, 3개 이상 격자, 회사 로고·포지션명·추천 근거, 선택, 더보기·접기와 400px 기준 좁은 배치를 제공한다. 원본 카드/격자 스타일은 36/53px 헤더, 16px 패딩, 12px 글자, 10px 간격, 선택된 카드의 2px 파란 테두리와 15px 패딩이다. 설치용 컴포넌트는 이 목적과 대표 스타일을 유지하고 회사 로고는 호스트 슬롯으로 받는다. 버전이 없는 오래된 카드는 참조 시 버전 1로 해석하고, 카드의 과거 버전과 본문 링크의 현재 운영본을 구분한다. API·권한·과거 이력 조회와 실제 패널 열기는 호스트 소유다.

원본의 좁은 화면에서는 `포지션 3개 더보기`라고 안내하면서 클릭 시 2개만 추가되는 경우가 있다. 설치본에서는 안내한 개수만큼 실제로 추가한다. 240px 이하에서는 한 열로 바꾸고 긴 텍스트의 원문은 `title`에 남긴 채 2/3줄로 제한한다. 문제가 있는 원본 형태를 그대로 재현하지 않는다는 완료 기준에 맞춘 개선이다.
