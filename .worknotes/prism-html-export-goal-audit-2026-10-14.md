# prism-html-export 목표 수용 감사 (2026-10-14)

현재 프런트엔드 `2eeb26ff10274745f9d86897c2f2828bff002b98`의 `CandidateProfileHtmlExport`와 `exportProfileHtml.ts`를 대조했다. 원본은 인쇄 미리보기와 같은 DOM을 화면 밖에 렌더한 뒤 툴바를 빼고 CSS·글꼴·이미지·canvas를 단일 HTML로 묶어 다운로드한다. 설치형 `createPrismHtmlDocument`/`PrismHtmlExportButton`은 소비자가 제공한 정적 문서 root에 같은 목적을 적용한다. 전체 7분류 문서의 내용과 페이지 구성은 별도 `prism-profile-print`의 책임이다.

설치형은 읽지 못한 사진·글꼴·스타일·차트를 외부 URL로 남겨 불완전한 독립 파일을 성공 처리하지 않는다. 실행 스크립트·이벤트 속성을 제거하고 CSP를 넣으며 현재 입력값과 정적 차트, 툴바 제외 규칙을 보존한다. 원본의 실패 시 외부 링크 유지보다 독립 파일이라는 목적에 맞는 개선으로 판단했다. 브라우저에서 볼 때 종이 너비가 화면보다 크면 문서 전체 대신 내부 viewer가 스크롤한다.

기존 HTML 내보내기 테스트는 DOM 스냅샷과 현재 form 값, canvas/사진 순서, CSS URL·image-set 파싱, 자산 캐시, 지연 자산 중 원본 변경 차단, CSSOM 실패, 중단 시 결과 없음 등을 검증한다. 이번 로컬 브라우저에서 기본 상태의 합성 HTML 3,342,784바이트를 다운로드했고 자산 3개를 포함했다. 파일에는 CSP, SUMMARY·경력·Risk, 인라인 자산이 있으며 외부 HTTP URL·script 태그·제외한 툴바가 없었다. 오류 상태는 자산 실패를 표시하고 성공 파일을 만들지 않았고, 로딩 상태의 즉시 취소는 대기 버튼을 기본 상태로 돌렸다.

새 격리 shadcn 소비자에 59개 PRISM 모듈을 설치해 현재 레지스트리의 HTML/PDF/인쇄 파일과 CSS가 바이트 단위로 같음을 확인했다. 52개 완전 사용 예제의 타입 검사와 Vite/Pretendard/고지 빌드가 통과했다. 설치본의 HTML 완전 예제를 실제로 실행해 3,057,190바이트 파일을 다운로드했다. 파일에는 글꼴과 경력 본문, CSP가 있고 외부 HTTP URL과 script 태그는 없었다.

이전 같은 구현의 브라우저 검증은 다운로드 파일을 오프라인에서 다시 열어 1280/320px 기본·긴 문서의 글꼴·차트·내부 스크롤을 확인했다. 이번 내장 브라우저는 `file:` URL 접근을 보안 정책으로 거부해 현재 파일을 다시 열지 못했다. 다른 경로로 우회하지 않고 파일 내용 검사와 이전 오프라인 검증을 구분한다. 이번 브라우저의 임시 320px viewport override도 실제 `innerWidth`를 바꾸지 않아 새 320px 측정으로 기록하지 않는다.

독립 HTML 생성·설치·대표 상태·의도한 개선이 확인되어 `prism-html-export`를 **55/58번째 완료 그룹**으로 판정한다. 미판정은 `prism-export`, `prism-print`, `prism-profile-print` 3개다. 인증된 운영 데이터/사진 권한, 배포 SHA와 현재 HTML의 실제 오프라인 재열기, 전 브라우저 CSS 문맥, 전체 7분류 문서의 내용·인쇄 쪽 나눔은 확인하지 못했다.

전체 사이트 빌드, PRISM 검사(362개 테스트·52개 완전 사용 예제), 워크스페이스 타입 검사, 레지스트리 릴리스 검사가 통과했다. 공개용 검증 기록과 생성된 `docs/` 사본은 모두 55/58개 수용, 고유 완료 그룹 55개, 미판정 3개로 일치한다.
