# 세션 기록 지침 점검

기준: 2026-09-28. 사용자는 Codex 세션의 계획, 검토, 인계 기록을
`.worknotes/`에 저장하고 변경 사항을 대화에서 알리도록 요청했습니다.

## 확인한 지침

- `skills.pydemia.ai`에서 공개된 Skill과 Prompt 상세 페이지 59개를
  확인했습니다. `.worknotes` 또는 세션 기록 위치를 지정한 본문은
  찾지 못했습니다. `software-engineering`은 작업 전후 문서와 검증을
  다루지만 저장 위치는 지정하지 않습니다.
- 로컬 `C:\Users\pydemia\.codex\AGENTS.md`와 이 세션에 전달된
  `AGENTS.md` 지침에도 `.worknotes` 규칙은 없습니다.
- ChatGPT 계정의 Personalization > ChatGPT custom instructions를
  화면에서 읽었습니다. 답변 문체와 Skill 조회 규칙은 있으나
  `.worknotes` 규칙은 없습니다. 설정은 변경하지 않았습니다.

## 이 저장소에서 고친 내용

- 이번 세션의 확장 계획과 persona 검토 자료를 `research/`에서
  `.worknotes/`로 옮겼습니다. `research/`에는 기존의 지속적인 조사·
  검증 자료를 남겼습니다.
- 인계 본문을 `.worknotes/NEXT_SESSION.md`로 옮기고 기존 루트 경로는
  안내 링크로 유지했습니다. 관련 Markdown 링크와 현재 roadmap 해시를
  갱신했습니다.
- 저장소 `AGENTS.md`에 기록 위치, 갱신, 사용자에게 경로를 알리는
  규칙을 추가했습니다. 이는 이 저장소에서 시작하는 향후 세션에
  적용하기 위한 로컬 규칙입니다.

공개 Skill 사이트, 로컬 전역 Codex 지침, ChatGPT 계정 설정은 수정하지
않았습니다. 다른 저장소의 세션에도 같은 규칙을 적용하려면 해당
전역 지침을 별도로 갱신해야 합니다.
