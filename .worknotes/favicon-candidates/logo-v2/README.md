# pydemia logo v2 UI icon 시안

2026-09-28. 사용자가 첨부한 네 로고 보드의 중앙 심볼을 각각
독립적인 UI icon으로 분리했습니다. 원본의 `pydemia` 글자와 발표용
배경·레이블은 포함하지 않았습니다. 생성 이미지의 투명 배경 위에
심볼만 남겼고 `preview.html`에서 작은 크기와 어두운 타일을 비교합니다.

| 원본 보드 | 시안 | 특징 |
| --- | --- | --- |
| 06C / Method | `06c-method.png` | 둥근 네 방향의 교차 |
| 06B / PD Return | `06b-pd-return.png` | 중앙에서 되돌아가는 획 |
| 04A / Iteration | `04a-iteration.png` | 절개된 바깥 육각형과 안쪽 고리 |
| 02A / Interweave | `02a-interweave.png` | 각진 리본과 대각선 여백 |

네 파일은 PNG 시안이며 최종 SVG 벡터 도안은 아직 작성하지 않았습니다.
따라서 작은 크기의 형태, 경로의 대칭성, 실제 favicon 적합성은
사용자 선택 후 벡터로 다시 그려 확인해야 합니다. 현재 사이트에는
어느 시안도 적용하지 않았습니다. 이전 A 시안 변형 파일은 유지합니다.

검사: 네 파일 모두 1254×1254px이고 바깥 모서리 alpha가 0입니다.
비교 페이지는 네 PNG를 모두 참조합니다. 16px 축소를 alpha 기준으로
확인했을 때 06B와 06C는 내부 틈이 촘촘해 작은 탭에서 형태가
뭉칠 가능성이 있습니다. 실제 브라우저 렌더링 검사는 수행하지
못했습니다.
