# pydemia-logo-v2 입체 컬러 시안

2026-09-28. 기존 `pydemia-logo-v2`의 확정 도형에 명암과 그라데이션을
적용한 시안입니다. 2D shade v4는 사이트 favicon으로 선택되었고,
3D 시안은 비교용으로 보관합니다.

## 색상과 형태

원본 패키지 `README.md`에 명시된 `modern-vintage` 적용 색상인 네이비
`#103344`, 마젠타·버건디 `#BA365B`, 잉크 `#1C181F`를 기준으로
삼았습니다. 그라데이션의 밝은 색과 중간색은 이 세 색에서 만든
명암 변형이며 colormap의 별도 공식 항목으로 취급하지 않습니다.

`pydemia-logo-v2-dimensional.svg`는 첫 시안이고,
`pydemia-logo-v2-dimensional-v2.svg`는 명암을 강화한 두 번째
시안입니다. `pydemia-logo-v2-dimensional-v3.svg`는 파란 모듈의
가운데 틈 주변과 오른쪽 끝 명암을 조정한 세 번째 시안입니다.
`pydemia-logo-v2-dimensional-v4.svg`는 너무 밝아진 파란 모듈의
오른쪽 끝을 다시 낮춘 현재 시안입니다. 네 파일 모두 승인된 SVG의
`p-module` 경로, 두 번째 모듈의 180도 회전, 투명 배경과 내부
여백을 유지합니다. `approved-source.svg`는 원본 네이비 SVG 사본입니다.

`pydemia-logo-v2-extruded.svg`는 네 번째 시안의 앞면 뒤로
오른쪽 10, 아래쪽 14 SVG 단위의 측면을 낸 별도 3D 시안입니다.
앞면 경로와 색상은 네 번째 시안과 같습니다. 측면은 네이비계
`#102A36`, 버건디계 `#702440`이며 외부 그림자는 없습니다.

각 PNG는 원본 컬러 PNG의 alpha를 보존하고 해당 SVG의 gradient stop을
적용한 미리보기입니다. 32px·16px 축소 파일도 만들었습니다.
`render-preview.ps1`은 네 번째 시안의 PNG를 다시 생성합니다.
`render-extruded-preview.ps1`은 3D 시안의 PNG를 생성합니다.
`approved-colorful-source.png`는 컬러 원본 사본입니다.

두 번째 시안은 그라데이션 범위를 로고의 실제 면적에 맞게 좁히고,
네이비 윗부분과 버건디 왼쪽 면을 조금 밝게, 반대쪽 끝을 조금 더
어둡게 조정했습니다. 추가 그림자나 새 입체 면은 넣지 않았습니다.

세 번째 시안은 파란 모듈의 가운데 투명한 틈 주변에만 짙은 네이비
`#103344` 음영을 최대 12%로 얹었습니다. 너무 어둡던 파란 모듈의
오른쪽 끝은 잉크 `#1C181F` 대신 네이비계 `#1C4152`로 밝히고,
버건디 모듈은 그대로 두었습니다.

사용자는 세 번째 시안의 끝색이 너무 밝아 광원이 부자연스럽다고
지적했습니다. 네 번째 시안은 끝색만 `#1C2732`로 바꿨습니다.
두 번째 시안의 `#1C181F`보다는 조금 밝고 중간색 `#103344`보다는
어두워, 끝으로 갈수록 어두워지는 흐름을 유지합니다. 가운데 틈의
국소 음영과 버건디 모듈은 세 번째 시안과 같습니다.

## 확인

- 세 번째 SVG의 경로 문자열이 승인된 원본과 같은지 확인했습니다.
- 세 번째 시안의 1728px, 32px, 16px PNG를 생성하고 눈으로
  확인했습니다.
- 24px 간격으로 원본과 두 번째 시안의 alpha를 비교한 결과 불일치가
  없었습니다. 색상은 보이는 픽셀 1,676개 중 1,626개에서 바뀌었습니다.
- 같은 간격으로 원본과 세 번째 시안의 alpha를 비교한 결과 불일치가
  없었습니다. 가운데 틈의 표본 픽셀도 alpha 0을 유지했습니다.
- 네 번째 SVG 경로가 원본과 같고, 1728px·32px·16px PNG를 생성해
  확인했습니다. 24px 간격 alpha 비교에서도 불일치가 없었습니다.
  파란 끝 표본은 2차 `#1C181F`, 3차 `#1C4152`, 4차 `#1C2732`입니다.
- 3D 시안도 승인된 앞면 경로를 사용합니다. 1728px·32px·16px
  미리보기를 확인했고, 가운데 구멍과 파란 상단 틈의 중앙 표본은
  alpha 0을 유지합니다. 작은 크기에서는 측면이 거의 보이지 않습니다.
- 실제 브라우저 탭의 favicon 렌더링은 별도 배포 검증 기록에서 확인합니다.
- built-in imagegen으로 먼저 투명 PNG 편집 시안을 만들었으나 경계에
  색 번짐이 보여 채택하지 않았습니다. 최종 시안은 원본 경로와 alpha를
  보존하는 SVG·PNG로 정리했습니다.

두 번째 시안에서도 built-in imagegen으로 안쪽 음영을 시험했으나
경계 번짐과 과한 그림자 때문에 채택하지 않았습니다.
세 번째 시안에서도 틈 주변만 수정하도록 imagegen을 시험했지만
버건디 쪽 투명 영역에 색 번짐이 생겨 채택하지 않았습니다.
3D 시안에서도 imagegen의 얕은 측면 표현을 참고했지만 모서리에
색 번짐이 있어 원본 경로 기반 SVG·PNG로 다시 만들었습니다.

imagegen 검토 프롬프트: 원본 p/d 육각 도형과 내부 여백을 유지하고,
네이비 `#103344`, 마젠타 `#BA365B`, 잉크 `#1C181F`로 절제된
상단 하이라이트와 하단 그늘을 추가한 투명 로고. 새 문자·배경·외곽선·
원근 변형은 추가하지 않음.
