# PRISM 사이드바 목표 감사 · 2026-10-14

- 기준: frontend `dev`와 `origin/dev`는 `2eeb26ff10274745f9d86897c2f2828bff002b98`이다. `ChatSidebar.tsx`와 `_chat-sidebar.scss`는 이전 인증 배포 측정에 사용한 `d677e551`에서 변경되지 않았다. 이전 측정의 280px 사이드바·64px 헤더·40px 새 대화·36px 메뉴 행·213px 긴 이력 행·256px 사용자 메뉴를 참고했다. 현재 인앱 브라우저의 `dev.prism.ai/chat`은 연결이 재설정되어 최신 배포 화면과 SHA를 직접 확인하지 못했다.
- 범위: 현재 원본의 후보자·즐겨찾기·포지션·5개 관리자 메뉴, 기록 펼침·100행 스크롤, 저장 전 행과 서버 대화 선택, 이름 변경·삭제, 관리자 권한과 로그아웃 노출 조건을 독립 컴포넌트·완전 예제에 대응했다. 이 목적은 이전 source/contract/browser 감사에서 검증됐다. 원본 메뉴는 우측에 열리지만 320px 로컬 미리보기에서는 256px 사용자 메뉴가 x=290–546px에 배치되어 화면 밖에 있었다.
- 개선: 메뉴 오른쪽에 256px+간격+여백이 부족하면 위쪽에 열도록 하고 ResizeObserver와 viewport resize로 위치를 갱신한다. 로컬 320px에서는 x=29–285px, 800px에서는 x=290–546px로 열렸고, 열린 상태로 800→320px로 줄여도 위쪽으로 복귀했다. 긴 이력 100행과 문서 넘침 0을 확인했다.
- 독립 설치: 별도 shadcn 소비자에 최신 `prism-sidebar`와 토큰을 다시 설치했다. 59개 모듈/CSS가 레지스트리 바이트와 일치하고 완전 예제 48개 타입 검사, Vite, Pretendard, 고지 및 PRISM 테스트 337개가 통과했다. 1280px viewport 속 320px 부모에서 사용자 메뉴는 x=13–269px, 부모 800px에서는 x=274–530px이었다. 좁은 부모의 공지사항 버튼이 호스트 callback을 호출했고 콘솔 오류는 없었다.
- 판정: 목적·대표 디자인·동작·독립 설치·반응형 개선을 확인해 `prism-sidebar`를 완료로 인정한다. 실제 인증 라우팅·세션·삭제 서비스, 현재 배포 클라이언트와의 동일 SHA, 전체 글리프/픽셀 일치는 확인하지 않았다.
