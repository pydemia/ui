# 데스크톱 사이드바 너비 조절

- 공통 Sidebar와 UI 카탈로그 탐색의 데스크톱 분할선을 드래그해 너비를 조절할 수 있다. 방향키와 Home·End도 지원한다.
- Registry의 pyd-sidebar는 크기 조절을 기본으로 사용한다. 접힌 상태 및 모바일에서는 분할선을 숨긴다. 필요하면 `resizable={false}`로 끌 수 있다.
- UI 카탈로그는 너비를 현재 브라우저에 저장한다.
- UI·문서 단위 테스트 321개·15개와 Registry 통합 테스트 5개를 통과했다. 156개 공개 항목과 신규 스냅샷의 일치를 확인했다.
- Edge 브라우저에서 카탈로그 드래그·새로고침, 공통 Sidebar 드래그·키보드·접기, 모바일 가로 스크롤 방지를 확인했다.
