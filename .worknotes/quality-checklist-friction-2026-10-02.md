# 공급·품질 체크리스트의 실제 부담 재검토

2026-10-02. 공개 기준은 116개 component, 118개 registry item,
36개 snapshot입니다. Goal 관리용 추정은 약 91%입니다. 이 문서는
기준과 절차를 검토한 기록이며 검사 코드, 출시 판정, 제품 동작을
변경하지 않습니다.

## 확인한 상태

현재 [로드맵](component-roadmap.md#공급과-품질의-판정-단위)의 원칙은
이미 변경 위험별 검사입니다. 같은 commit의 CI를 재사용하고,
상호작용은 자동 테스트 또는 브라우저 중 적합한 방식으로 확인하며,
표준 registry item마다 소비자 설치를 반복하지 않습니다. 이 원칙
자체를 더 느슨하게 바꿀 근거는 확인되지 않았습니다.

운영 부담은 다음 부분에서 남아 있습니다.

- 로드맵의 적용 기준 뒤에 같은 내용을 여섯 단계의 완료 조건으로
  반복합니다. 두 목록을 모두 점검해야 하는 것처럼 읽힙니다.
- `.github/workflows/verify.yml`은 모든 PR에서
  `registry:release-check`를 실행합니다. 이 명령의 `verify-current`는
  현재 빌드와 일치하는 전체 snapshot이 없으면 실패합니다.
  `registry-release.mjs`의 `create`는 item 하나가 달라져도 새 ID 아래
  모든 item JSON을 복사합니다. 공개 전 중간 수정마다 이 파일들이
  PR diff에 생길 수 있습니다.
- 적용되지 않는 환경을 모두 `미검증`으로 적으면 실제로 확인해야 할
  위험과 무관한 검사도 매번 남은 과제처럼 보입니다. 특히 정적 표시
  변경에 서버 조회 경합이나 touch 동작을 적을 필요가 없습니다.

## 권장하는 판정 방식

공급 완료에는 세 가지를 확인합니다. (1) 해당 commit의 적용되는
CI, (2) 변경한 핵심 사용 흐름의 실행 증거, (3) 공개 경로의 일치와
배포 확인입니다. 새 component의 독립 사용처, export, registry,
출처, preview, Usage는 세 번째 항목의 구체적인 확인 대상입니다.
정적 표시 변경에서는 preview 확인이 흐름 증거가 될 수 있습니다.
복수의 독립 상호작용을 새로 만들었다면 각 핵심 흐름을 확인합니다.

외부 코드 도입, 새 focus·pointer·browser API·반응형 배치, 새 설치
경로에 대한 추가 검사는 그 위험이 생긴 변경에만 적용합니다.
검사 결과는 `통과`, `해당 없음`, `미검증`, `차단`으로 구분합니다.
`미검증`은 실제로 적용되지만 실행하지 못한 검사나 명시적으로
지원 범위를 평가하는 환경에 씁니다. 적용되지 않는 검사를
`미검증`으로 누적하지 않습니다.

확인된 값 손실, 제출 오류, keyboard 접근 불가, 필수 고지 누락,
설치 실패, 적용되는 CI 실패는 계속 차단합니다. 핵심 동작을 어느
방식으로도 실행하지 못했다면 공급 완료로 세지 않습니다.
screen reader·touch·Safari·RTL의 지원을 주장하거나 관련 경로를
변경할 때는 해당 검사를 적용합니다. 라이브러리 전체의 표본 조사와
rollback 뒤 URL 보존은 별도 운영 과제로 둡니다.

## 절차 개선 순서

먼저 로드맵의 여섯 단계와 위 적용 기준을 한 곳으로 합치고,
릴리스 기록에는 변경 유형·대표 증거·차단 사항만 적는 편이
명확합니다. CI 변경 없이 문서의 중복을 줄일 수 있습니다.

snapshot 부담을 줄이려면 초안 PR의 정합성 검사와 실제 공개 후보의
불변 snapshot 검사를 분리해야 합니다. 현재는 `main` 병합 뒤
배포가 시작되므로 공개 후보의 snapshot 생성·검사는 병합 전에
완료되어야 합니다. 단순히 PR에서 `verify-current`를 제거하면
공개 snapshot 누락을 막던 검사가 사라집니다. 이 변경은 CI의
필수 상태, 릴리스 후보 판정, 배포 순서를 함께 설계한 별도 작업으로
다룹니다. provenance의 고정 출처와 시점별 검증 결과를 분리하는
작업도 같은 이유로 별도 범위입니다.

이번 검토로 component 수나 goal 진척도를 올리지 않습니다.
코드·CI·브라우저 검사는 실행하지 않았습니다.
