# 예시 데이터의 외부 UI 라이브러리 이름 정리

2026-09-29. 사용자는 Table 예시와 그 밖의 예시에서 외부 UI 라이브러리
이름을 제거하고 다른 내용으로 작성하도록 요청했습니다.

- 문서의 Table preview와 사용 코드를 가상의 화면 개선 요청 2건으로
  바꿨습니다. caption과 열 머리글은 새 데이터에 맞췄습니다.
- 조합 예시의 표를 컴포넌트 요청 4건으로 바꿨습니다. 검색은 요청 제목,
  담당, 범주를 대상으로 유지하고 빈 결과 문구도 바꿨습니다.
- 조합 예시의 제목·설명과 component 설명에서 외부 라이브러리 이름을
  동작 설명으로 바꿨습니다.
- 실제 소스 출처, 라이선스, dependency를 기록한 `registry/provenance.json`,
  `THIRD_PARTY_NOTICES.md`, 조사 문서는 유지했습니다. 공개 문서의
  SOURCE/LICENSE 항목과 실제 설치 명령도 출처·사용법 정보로 남깁니다.

## 검증

- `npm run typecheck`, `npm run build`, `npm run registry:check` 통과.
- 빌드된 문서의 Table preview에서 caption·열·두 요청을 확인했습니다.
- 조합 예시에서 네 요청이 표시되고 담당 검색이 한 건으로 좁혀지며,
  결과가 없을 때 안내 문구가 나오는 것을 브라우저에서 확인했습니다.
- 이번 변경은 예시 문구와 데이터에 한정됩니다. 법률 검토는 수행하지
  않았습니다.
